# Менеджер проектов

Бесплатное веб-приложение для монтажников слаботочных систем: точки проекта (камеры, двери, вайфай…), чертежи, протяжки, метраж,
шкафы и шильют, ежедневные отчёты на русском и иврите, таблицы для руководства. Работает офлайн, ставится на экран телефона.

**Открыть:** https://kukilvan.github.io/project-manager-app/

## Как начать

1. Откройте ссылку выше с телефона или компьютера.
2. Если коллега прислал «ссылку для подключения» — откройте её и войдите своим Google-аккаунтом. Всё.
3. Иначе пройдите мастер настройки (≈10 минут, удобнее с компьютера): приложение поведёт по шагам — создать бесплатный проект Firebase,
   включить базу и вход через Google, вставить правила и настройки. Ваши данные хранятся только в вашем проекте Firebase.
4. Добавьте приложение на главный экран телефона (меню браузера → «На экран “Домой”» / «Установить приложение»).

Приложение обновляется само: новые функции приходят всем автоматически.

Подробное руководство и тур — внутри приложения (☰ → Руководства).

## Для разработчика

```
npm install
npm run dev      # локально
npm test
npm run build    # сборка в dist/ (адрес сайта: VITE_BASE, по умолчанию /project-manager-app/)
```

- Vite + Firebase (Auth + Firestore с офлайн-кэшем), публикация через GitHub Pages.
- Правила базы: `firestore.rules` (база автора) и `firestore.open.rules` (для всех, создаётся из первого функцией `openRules`, сверяется тестом).
- Как сохранить и восстановить всё на другой площадке — [ВОССТАНОВЛЕНИЕ.md](ВОССТАНОВЛЕНИЕ.md).
