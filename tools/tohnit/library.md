# Библиотека обозначений на тохнитах (слаботочка, Израиль)

Пополняется после каждого проекта. «→ тип» — тип точки в «Полевом журнале». «не точка» — не создавать.

**Главное: тип определяй по значку рядом с подписью и по легенде чертежа (מקרא).** Вид подписи — только подсказка: у разных проектировщиков `C2/1` — камера, а `C` — может быть и что-то другое.

## Номера точек (то, что становится точкой)
| Как выглядит | Что это | → тип |
|---|---|---|
| `1A-C154`, `C154`, `1-C66`, `C2/31` (у купольной камеры), `B3-CTV-IP-CAB-B03-01` (CTV/CAM/CCTV) | камера | Камера |
| `1A-Z66`, `Z043`, `2/Z-1` (кружок «360 AM») | галай (датчик движения; 360 AM — потолочный с антимаскингом) | Галай |
| `1A-AP-04`, `AP-03`, `W2/1`, `WIFI`, `WAP` | точка доступа Wi-Fi (аксэспоинт) | Вайфай |
| `1A-17.1`, `2B-7.2`, `D-14`, `CAB2-D62`, `D2/5` | дверь (СКУД). `.1/.2` — две разные двери | Дверь |
| `P-1`, `P` в кружке у стола (לחצן מצוקה) | тревожная кнопка | Тревожная кнопка |
| `2B/01-02`, `1A/03-04`, `B10,11` | бакар (контроллер), пара номеров = одна точка | Бакар |
| `P26`, `X1`, `X2`, `RJ45`, `TL` у розетки | точка связи (розетка RJ45). `X2` = 2 розетки (берём, только если Иван делает розетки связи на этом проекте). `X2` рядом со значком бакара — 2 кабеля бакара, НЕ отдельные точки | Точка |
| `TV`, `TV-140`, `TV 210`, `TVX1` | точка TV. Число под/рядом с TV — размер экрана или высота, не номер. Делает ли Иван TV — спросить | TV |
| `FO`, `Fiber`, `סיב אופטי` | оптика | Оптика |
| `APA` | лахцан птиха на столе (отдельная точка, 1×6005) | Лахцан птиха |
| `OB` | тревожная кнопка (лахцан мецука), отдельная точка, 1×6005 | Тревожная кнопка |

## Компоненты двери — НЕ отдельные точки (входят в дверь)
`CR` (коре картис), `M`/магнит, `EL…`/`EFF118/138`/`Electrical lock`/`Electro mechanical` (замки), `AC door`, `B1`/`B2` (тип замка), `KB` (киборд), `BG` (лахцан швира/нипуц), `I`, `I-S`, `I-C` (интерком-варианты у двери — уточнить), `M` у двери.
Если у двери на чертеже есть набор значков — это можно отметить в примечании точки, но строк не создавать (кроме BRFC/APA/OB/INT по правилам выше).

## Схема подписей «система-шкаф-устройство-номер» (например, Elkana)
`B3-CTV-IP-CAB-B3/01-14`: `B3` — этаж, `CTV` — камеры, `ACS` — СКУД, `ALR` — сигнализация, `INT` — интерком, `IP-CAB-B3/01` — шкаф, `14` — номер.
- `…-ACS-…-CR-NN` — дверь (одна точка на дверь, номер — по CR). `EM` (электромагнит), `PB` (кнопка выхода), `DP`/`DC` (датчик положения двери), `BG` (лахцан швира) — части двери, не точки.
- `…-ALR-…-DC-NN` может быть тревожной кнопкой у стола — смотри, куда ведёт выноска.
- «ACCESS POINT» в рамке — Вайфай (часто без номера). `LPR` — камера LPR.
- `R1…R20` в серых рамках — номера комнат. Система вызова медсестры (`ל-ח`, `ל-ק-ד`, `נורית סימון`) — не наша.
- Таблица «סה"כ אביזרים במפלס» — количества по этажу: сверять.
- `…-CTV-IP-CAB-R5` — камера палаты R5: шкаф в подписи не указан (спросить; часто — ближайший). В палате бывает 2–3 значка камеры, а подписан один: неподписанные искать через `symbols` + `only_unlabeled`.
- Номера в шкафу бывают общими для всех систем (CTV, INT, ACS): «пропуск» в серии камер может быть занят интеркомом — проверь через `find`.
- «ACCESS» / «POINT» — две строки SHX-аннотации: точка одна (вторую строку `skip`).
- SHX-иврит в старой кодировке: `sk, pry N` = «דלת פרט N» (место двери по детали N).

## Пометки рядом с точкой — читать обязательно (на картинке, иврит в тексте PDF перевёрнут)
- `באחריות לקוח` — «на ответственности заказчика»: не наша точка (спросить Ивана).
- `עתידי` — будущее, `קיים` — существующее: обычно не делаем сейчас — спросить.
- Красные зачёркивания, облака, пометки от руки поверх точки — отменена/изменена — спросить.

## Никогда не точки
- Номера помещений (часто голубые рамки `FT-01`, `GO-03-01`, `YE-04`, числа в углах комнат, `121`, `3-63`).
- Высоты установки: `H=1.20`, `H240`, `H170`, `+1.10`.
- Размеры, отметки уровней (`-29.41`, `+246.15`), площади (`m²`), масштабы, даты, номера листов, штамп.
- Шкафы и стойки: `CAB-1A`, `RACK-80/80`, `ארון תקשורת`, `CRAC`.
- Типы кабелей и устройств в легенде, сноски, номера осей (`A`, `1`, `2` в кружках).
- `ACP`, `CH-…`, `BA…BK` на Mega Or — чужие системы (подтверждено Иваном).

## Чертежи только со значками (без номеров)
- Цифра внутри значка = число розеток (`1`, `2`); цвет фона значка различает виды (синий/белый/красный/магента).
- Легенда часто даёт «Quantity N, M Outlets» — это контрольные числа, сверять обязательно.
- Значки находит `blobs` (виды по цвету/форме/букве внутри). Обозначения придумываются: префикс вида + номер; каждый вид с 1, слева направо цепочкой по соседям. Их нужно нанести на чертёж до протяжки — для этого отдаётся PDF с номерами (build).
- Серые рамки колонн и штриховки (слои `KOTERET`, `*Hatch*`) — скрывать командой `hide`.
- **Ашдод, стадион (IZIKCOM), подтверждено Иваном:** красные коробки A/B/C/TV → тип «Точка», одна общая серия чисел без букв: A = 4 кабеля (N.1–N.4), B, C, TV = 1 кабель (N). F у камеры — розетка самой камеры, не точка. WL (מכלול בתקרה) → Вайфай W01…. B у LCD — точка, экран LCD не точка. Все камеры (F / PTZ / купола) → C01… одной серией. Двери: треугольник «1» → 1D01…, «2» → 2D01…. M H.D (тяжёлый магнит) → «Магнит индикация», M01…. R (רמקול תיקרתי) → «Рамколь», R01…. Галаи → G01…. Чёрный «H» в квадратике у дверей — не из легенды, не точка. Все точки без шкафа и без этажа в обозначении.
- Пример того же чертежа: красные рамки с буквами A/B/C/F/TV/WL/J/H — розетки связи по деталям (פרט); голубые значки — камеры (F — קבועה, PTZ, DOM); синие треугольники 1/2 — двери по פרט 1/2; зелёные CR/BZ/PB/BG/M/EM — части двери (не точки); оранжевый I — интерком; розовые R/LCD — громкоговорители/экраны (спросить).

## Особенности проектов
- **Mega Or (Модиин), этаж 0 (200A_DC1_GF), подтверждено Иваном:** шкафы GA1, GA2, GB, GC, GD1, GD2 — шкаф = буквы до «/» (`cabinet_regex: "^(G[A-D]\\d?)/"`). `X/C-NN` → Камера; `X/D-NN.1/.2` → двери: в табличке двери `אלקטרומגנט` → «Дверь ЭМ 3 кабеля», остальные (ISEO, EL 560, EL, без таблички) → «Дверь МХ 3 кабеля»; `X/AP-NN` → Вайфай; `X/NN-NN` (значок B) → Бакар; `X/RNN` (у BRFC) → «Коре биометри», BRFC без R-номера не брать (двери заказчика / «להכנה בלבד»); `X/NN.In-NN` — тип по значку рядом (`by_icon`): синий треугольник → «Магнит индикация», фиолетовый шестиугольник → «Галай», у двери с OB/BB без значка → «Магнит индикация»; номер входа (In-03/In-04) на тип НЕ указывает; `X/NN.O-NN` (салатовый кружок) → «Цофар - сирена»; OB/BB у двери — не точки; APA у интеркома → «Тревожная кнопка» (`GD1/IN-02-APA`); `X/U01-12` (נק' לדלפק) → 12 точек «Точка»; `X/IN-NN` → Интерком. Камеры без подписи — нумеровать продолжением серии шкафа по месту (Иван просил), с пометкой. Квадрант «לא לביצוע בשלב זה» — точки всё равно включать. «באחריות לקוח» стрелкой указывает на соседнюю дверь, а не на подписанную. На этом чертеже «באחריות לקוח» и «להכנה בלבד» в тексте PDF — в искажённой кодировке («בנתציוח לרות», «בלבב למכצמ»): find по искажённому виду. Дубли — оставлять `#2`, Иван исправит.
- **Названия типов — буква в букву как в приложении** (Mega Or: «Дверь МХ 3 кабеля», «Дверь ЭМ 3 кабеля», «Цофар - сирена», «Магнит индикация», «Коре биометри», «Тревожная кнопка»). Тип, которого в проекте нет, приложение создаст само (из общего пула типов, иначе пустой) — поэтому опечатка в названии даст лишний тип; не уверен в названии — спроси.
- **Mega Or (Модиин), галерея**: шкафы 1A и 2B. На галерее `2A/01-02…2A/19-20` = наши `1A-01-02…1A-19-20`; `2-7.2`, `2-16.1…` = `2B-…`; `1-C66`, `C70–C72`, `1-C80…`, `2-C68…`, `Z49…`, `Z043…`, `CAB1-D…`, `CAB2-D…` — готовая часть здания, не наша. Двери: проектировщик иногда пишет одно обозначение дважды (`2B-10.1` вместо `2B-10.2`).
